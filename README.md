# beer-supply-chain-simulation
Python simulation of classic beer supply chain simulation problem, initially invented by MIT 

<img width="2500" height="1500" alt="supply_chain_simulation" src="https://github.com/user-attachments/assets/68d9a34b-f383-4776-abcc-b48866c74dc9" />

As you vary the parameters, you can even visualize the well known bullwhip effect, as well as starvation effects. 

This supply chain is 3 staged - 1 Factory, 2 Wholesalers/RDC (Regional Distibution Centers), 5 Retailers.
